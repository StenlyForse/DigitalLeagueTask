Основное задание:

Необходимо создать проект на net 8 web api приложения. 
Его основной задачей является шлюзовой механизм предоставления информации из сайта Банка России по курсам валют (на сайте Банка России cbr.ru есть вся необходимая информация по сервису, необходимо выбрать оптимальный).
На вход приложение получает GET запрос с внутренних систем организации на получение курса валют. Параметры: дата курса (если не передана, то используется текущая дата), код валюты (если не передан, то список всех валют). 
Приложение должно подключится к сайту Банка России взять оттуда необходимые курсы и сформировать соответствующий ответ в формате Json (код ответа 200). При отсутствии заданной в параметрах валюты ответ с кодом 204.

Дополнительные задачи, они не обязательны, но существенно повысят ваши позиции среди других соискателей.
Описать сервис в OpenAPI 3.0, в файле yaml.
Сформировать Jenkins пайплайн для сборки и контейнеризации приложения
Описать парой предложений, как бы вы переработали данный сервис для асинхронного получения информации с сайта Банка России
